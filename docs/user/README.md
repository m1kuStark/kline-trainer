# 用户指南

A股K线训练器读取本机通达信日线，供你练习逐日判断、买卖和画线。所有买卖都发生在模拟账户里。

安装和首次配置见[安装与配置](install.md)；录制、回放与分享见[录制说明](recording.md)；遇到问题先查[常见问题](troubleshooting.md)。

## 一次训练的完整流程

1. **创建训练**：明确选择一只股票、一个观察区间（1M/3M/6M/1Y/2Y）、起始日和初始资金（默认100万，可改）。训练从起始日开始，你只能看到起始日及之前的行情。
2. **逐日推进**：按空格推进到下一个交易日，图表加载当天的K线。
3. **买卖**：按当日收盘价成交。按 `B` 买入、`S` 卖出；买入按总权益计算目标仓位并向下取整到100股（整手），默认T+1（当天买入次日才能卖出）。费用默认关闭，创建时可开启。
4. **画线与观察**：随时在图上画线辅助判断，画线按训练保存。
5. **结算**：可以提前结算、持有到计划结束日自动结算，或放弃这笔训练。到期时如果本地数据还没覆盖到结束日，训练会等待你更新数据；已结算的训练不会自动重开。

同一时间只有一笔进行中的训练，开新训练前需要先结算或放弃当前训练。

## 快捷键与图表操作

| 按键 | 作用 |
|---|---|
| 空格 | 推进到下一交易日 |
| B / S | 买入 / 卖出 |
| ↑ / ↓ | 放大 / 缩小K线 |
| ← / → | 移动十字光标 |
| Home | 恢复默认视图 |
| `]` / `[` | 切换 日→周→月 周期（反向切换） |
| Delete | 删除选中的画线 |
| Esc | 退出画线模式或画线多选 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做画线（Ctrl+Y 也可重做） |

- 观察周期可切日/周/月，但推进粒度恒为一天。
- 指标：MA、VOL、MACD。K线为红涨绿跌，阳线空心、阴线实心。
- 主图空白处向右框选放大、向左框选缩小；滚轮平移历史，价格轴滚轮缩放纵轴；VOL/MACD 区域双击可最大化。

输入文字、编辑弹层打开或正在画线时，快捷键会被隔离，不会误触发交易。

## 画线工具

图表工具栏提供23种画线，包括线段、价位线、价格通道、斐波那契、几何图形、箭头和文本。

- 新画线默认为黄色1px虚线；颜色、粗细、线型、端点价格都可以编辑，支持多选、移动、撤销/重做/清空。
- 画线保存在训练数据库里，与这笔训练绑定，重启后仍在。
- 显示方式在创建训练时锁定（默认前复权）。发生分红送转后，已有画线会自动换算到新的前复权价格；但**早期版本保存、缺少基准信息的画线会按原值显示，不做自动换算**，如位置不对可手动调整。

## 行情数据从哪来

先在通达信下载日线和权息数据，再回训练器点“更新日线”。该按钮只重新扫描本地文件，不联网下载，也不修改通达信文件。目录与文件清单见[安装说明](install.md)。

## 数据存放在哪里，如何备份

训练器的数据分两处，备份需要两边都考虑：

- **训练数据**默认在 `%USERPROFILE%\.a-share-kline-trainer`。等待保存完成，运行包内 `Stop.cmd` 确认停止后，复制整个目录。自定义数据库须一并保留同名 `-wal`、`-shm` 文件，详见[备份说明](troubleshooting.md#备份前先停止训练器)。
- **训练录像**保存在浏览器的 IndexedDB 里，按访问地址（`127.0.0.1:8787`）区分。清理浏览器数据、换浏览器、换端口都会让已存录像"看不见"，重要录像请先导出（见[录制说明](recording.md)）。

数据库备份不含录像。录像含回放所需的行情、操作、画线和训练状态，但导入后只供观看，不会恢复可继续操作的训练。完整备份需要两者。

## 升级与移动

- 升级前先运行旧目录的 `Stop.cmd`，再解压新包并复制原来的 `trainer.config.json`；默认数据目录不变。
- 尽量保持端口（默认8787）和浏览器不变，否则训练录像会按新的访问地址分开存放。
- 桌面快捷方式指向解压目录里的 `Start.cmd`，移动或重命名该目录后需要重新创建快捷方式。
